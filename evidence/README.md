# Evidence folder

`benchmark.csv` and `benchmark.png` are generated by `experiments/benchmark.py`. They contain a one-trial, 1 MiB localhost smoke measurement produced while validating this package. They demonstrate that the experiment pipeline runs; they are not Mininet results and should not be presented as the final SDN performance evaluation. Re-run with `--trials 3` on the project VM, then complete the static-path/failover table in `experiments/mininet_failover.md` using real measurements.
